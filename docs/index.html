Dein Browser. Dein Stil.

Mach Nexlori zu deinem Nexlori.

Entdecke Farbwelten für deine Browseroberfläche. In Nexlori genügt ein Klick auf „Aktivieren“ – ohne Theme-ZIP-Dateien und ohne Downloads-Ordner voller Dateien.

So funktioniert es: Öffne diese Galerie in Nexlori und klicke bei einem Theme auf „Aktivieren“. Nexlori übernimmt die Farben direkt. Die Galerie kann nur Themes aktivieren, die in deiner installierten Browser-Version enthalten sind; sie führt keinen fremden Code aus.
